# FedEx Logistics Performance Analysis

Exploratory Data Analysis of FedEx Logistics Supply Chain Delivery History using Python.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

**Dataset:** 10,324 records and 33 columns.

**Key Findings:**
- 61.26% deliveries were on time.
- 27.26% deliveries were early.
- 11.49% deliveries were late.
